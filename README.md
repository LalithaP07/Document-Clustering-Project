# Document-Clustering-Project
Project Description:
This project focuses on document clustering using K-Means clustering in Python. It involves processing text data (articles/documents), converting them into numerical vector representations, clustering them into meaningful groups, and visualizing the results.

Key Features:
✔ Text Data Input – Load and preprocess multiple documents/articles.
✔ Vector Representation – Convert text into numerical vectors using techniques like TF-IDF.
✔ K-Means Clustering – Apply clustering algorithms to categorize documents into meaningful clusters.
✔ Data Visualization – Display the clustered results through graphical representations.

Tech Stack:
🟢 Python (Pandas, NumPy, Scikit-learn, Matplotlib, NLTK)
🟢 Natural Language Processing (NLP)
🟢 Machine Learning (K-Means Clustering)
